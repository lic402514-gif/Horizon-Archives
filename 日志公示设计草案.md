# 日志公示设计草案

根据日志设计，建议将日志划分为 **公开透明日志（Public Transparency Log）** 与 **内部审计日志（Internal Audit Log）**。其中仅将具有公共监督价值、不会泄露隐私的信息公开。

------

## 一、公开日志类型

| 日志类型                 | 是否公开  | 说明                                 |
| ------------------------ | --------- | ------------------------------------ |
| 图书创建（create book）  | ✅         | 新增图书元数据                       |
| 图书修改（update book）  | ✅         | 修改图书信息                         |
| 图书删除（delete book）  | ✅         | 删除图书                             |
| 图书发布（publish book） | ✅         | 发布静态页面                         |
| 文章创建/修改/删除       | ✅         | 内容更新历史                         |
| 作者创建/修改/删除       | ✅         | 元数据维护                           |
| 出版社创建/修改/删除     | ✅         | 元数据维护                           |
| 标签创建/修改/删除       | ✅         | 分类维护                             |
| 分类创建/修改/删除       | ✅         | 分类体系维护                         |
| 资源上传（upload asset） | ✅         | 新资源上传（隐藏真实 OSS 信息）      |
| 资源删除（delete asset） | ✅         | 删除资源文件                         |
| 邀请码创建/作废          | ✅（可选） | 可仅显示数量或编号，不公开邀请码内容 |
| 用户封禁/解封            | ✅         | 社区治理透明                         |
| 角色权限调整             | ✅         | 权限变更透明                         |
| 系统重建（rebuild）      | ✅         | SSG 重建记录                         |
| 自动任务（Automation）   | ✅         | 自动生成页面、索引等                 |

------

## 二、不建议公开的日志类型

| 日志类型                   | 原因                     |
| -------------------------- | ------------------------ |
| page_views（页面浏览日志） | 涉及访问行为与隐私       |
| download_logs（下载日志）  | 可推断用户阅读内容       |
| 登录成功/失败日志          | 容易被用于分析管理员活动 |
| JWT 刷新日志               | 无公开价值               |
| Session 日志               | 涉及身份认证             |
| API 调用日志               | 属于内部运维信息         |
| SQL 执行日志               | 安全风险                 |
| OSS 操作明细               | 暴露存储结构             |
| 系统异常栈                 | 暴露实现细节             |
| 安全防护日志               | 可帮助攻击者分析系统     |

------

## 三、公开日志保留字段

| 字段                       | 保留 | 说明                                                |
| -------------------------- | ---- | --------------------------------------------------- |
| id                         | ✅    | 日志唯一编号                                        |
| timestamp                  | ✅    | 操作时间                                            |
| action                     | ✅    | 操作类型                                            |
| target_type                | ✅    | 操作对象类型                                        |
| target_id                  | ✅    | 资源编号                                            |
| detail（脱敏）             | ✅    | 简要说明                                            |
| result                     | ✅    | success / failure                                   |
| operator_role              | ✅    | Library Admin、Account Admin、System、Automation 等 |
| version（建议新增）        | ✅    | 当前版本号                                          |
| change_summary（建议新增） | ✅    | 修改摘要                                            |
| commit_id（建议新增）      | ✅    | 审计编号                                            |

------

## 四、公开日志去除字段

| 字段                   | 去除原因                  |
| ---------------------- | ------------------------- |
| user_id                | 身份隐私                  |
| username               | 身份隐私                  |
| ip_address             | 网络隐私                  |
| session_key            | 浏览器身份标识            |
| user_agent             | 浏览器指纹                |
| referer                | 可能泄露来源页面          |
| JWT Token              | 身份认证信息              |
| Cookie                 | 身份认证信息              |
| 请求 Header            | 无公开价值                |
| 请求 Body              | 可能包含敏感数据          |
| 响应 Body              | 可能泄露内部实现          |
| OSS Object Key         | 暴露存储结构              |
| 文件真实路径           | 暴露服务器结构            |
| 数据库主键（内部对象） | 无公共价值（若非资源 ID） |
| GeoIP 信息             | 隐私数据                  |
| Email                  | 用户隐私                  |
| 手机号                 | 用户隐私                  |
| 密码 Hash              | 严禁公开                  |
| 权限 Token             | 严禁公开                  |

------

## 五、detail 字段建议脱敏规则

| 原始内容                | 公开内容                   |
| ----------------------- | -------------------------- |
| 《资本论》              | 《资本论》                 |
| 修改 ISBN               | 修改 ISBN                  |
| 修改封面                | 修改封面                   |
| 上传 `book_001.pdf`     | 上传数字资源               |
| 删除 `oss://bucket/...` | 删除数字资源               |
| 重置用户密码            | 重置用户密码               |
| 修改邮箱                | 修改用户资料               |
| 登录失败（密码错误）    | 登录失败                   |
| 权限不足删除用户        | 权限不足（删除用户操作）   |
| 邀请码 `ABCDEF123`      | 创建邀请码（隐藏具体内容） |

------

## 六、公开日志最终字段

```text
Log ID
Time
Action
Resource Type
Resource ID
Resource Name
Change Summary
Operator Role
Result
Version
Commit ID
```

例如：

| Log ID | Time             | Action  | Resource | Resource ID | Resource Name | Summary          | Operator      | Result  |
| ------ | ---------------- | ------- | -------- | ----------- | ------------- | ---------------- | ------------- | ------- |
| 10235  | 2026-07-15 09:15 | update  | Book     | 1523        | 《资本论》    | 修正 ISBN        | Library Admin | Success |
| 10236  | 2026-07-15 09:20 | publish | Book     | 1523        | 《资本论》    | 重新生成静态页面 | System        | Success |
| 10237  | 2026-07-15 09:45 | ban     | User     | 87          | User #87      | 封禁账户         | Account Admin | Success |

这样的公开日志既能满足透明度和可审计性，又不会泄露管理员或普通用户的隐私信息。
